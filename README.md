# Madiyar — Business Card Website

Бұл жеке визитка сайты. Бір бетте менің атым, мамандығым, қолданатын құралдарым және байланыс сілтемелері көрсетіледі. Сайт таза HTML мен CSS-пен жазылған, ешқандай кітапхана қажет емес.

## Мүмкіндіктер

- Бір файлдағы (`index.html`) жеңіл және жылдам бет
- Телефон мен компьютерге бейімделген дизайн
- Жарық және қараңғы тақырыпты құрылғы баптауына қарай өзі таңдайды
- Пернетақтамен жұмыс істейтін сілтемелер (focus көрінеді)
- GitHub Pages арқылы тегін жариялауға дайын

## Қолданылған технологиялар

| Құрал | Не үшін |
| --- | --- |
| HTML5 | Беттің құрылымы |
| CSS3 | Дизайн, тақырыптар, бейімделу |
| Git және GitHub | Нұсқаларды сақтау және жариялау |
| VS Code | Код жазу ортасы |

## Компьютерде ашу

1. Репозиторийді көшіріңіз:
   ```bash
   git clone https://github.com/USERNAME/business-card.git
   cd business-card
   ```
2. `index.html` файлын браузерде екі рет басып ашыңыз.

Өзгерістерді жылдам көргіңіз келсе, VS Code-та Live Server кеңейтімін қолдануға болады.

## Өз мәліметтеріңізге ауыстыру

`index.html` файлын ашып, мына жерлерді өзгертіңіз:

- `<h1>` ішіндегі есім және `.role` ішіндегі мамандық
- `.about` бөліміндегі өзіңіз туралы мәтін
- `href` ішіндегі `USERNAME` және `you@example.com` мәндерін өз GitHub, Telegram және поштаңызға ауыстырыңыз
- Түстер `:root` ішіндегі `--acc`, `--bg` айнымалыларында тұр

## GitHub Pages арқылы жариялау

1. GitHub-та репозиторийді ашып, **Settings** бөліміне өтіңіз.
2. Сол жақ мәзірден **Pages** бөлімін таңдаңыз.
3. **Build and deployment** ішінде **Source** мәнін **Deploy from a branch** деп қойыңыз.
4. **Branch** ретінде `main` және `/ (root)` таңдап, **Save** басыңыз.
5. 1–2 минуттан кейін сайт мына мекенжайда ашылады:
   `https://USERNAME.github.io/business-card/`

## Өзгерісті GitHub-қа жіберу

```bash
git push origin main
```
